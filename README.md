# TaskPilot

**نظام لإدارة حسابات العمل والمهام المستلمة من مجموعات واتساب، مع تطبيق Windows وخدمة مركزية دائمة على New-VPS.**

> الحالة: **نسخة شخصية بوظائف مختبرة محددة؛ قبول سير عمل المالك مستمر** — الخادم على New-VPS وتطبيق Windows المثبّت بالإصدار 0.10.0. تحققنا من فتحه من اختصار سطح المكتب واتصاله بالخادم. ربط Tailscale محفوظ دون مهلة جلسة، ولوحة تحكم منظمة وإشعارات عمل منفصلة عن سجل النشاط. المساعد الشخصي يبحث في السجلات ويعرض الحسابات ومصادرها ومهامها والاستقبال والأولويات والمراجعات والردود، ويجهز تغيير الحالة والأولوية لتأكيدك. يمكن إضافة مفتاح OpenRouter من إعدادات الذكاء الاصطناعي ولصق معرّف النموذج مباشرة في المساعد أو إعدادات الذكاء الاصطناعي. DeepSeek مختبر بملخص حي دون إرسال قيم شخصية؛ ردود واتساب تُعتمد بالمعاينة؛ اختُبرت الدفعة المقتبسة والألبوم في مجموعة الاختبار فقط. المحاكاة معطلة والبيانات والهوية محفوظة. [دليل الاستخدام](docs/16_PERSONAL_USE.md)، [دليل المساعد](docs/17_PROJECT_SECRETARY.md)، و[الأدلة وحدود القبول](tracking/PROJECT_STATE.md). آخر تحديث 2026-11-19.

## الرؤية
استقبال الرسائل من مجموعات محددة مرتبطة بجلسات واتساب، واستخراج بيانات الحسابات بإشراف المستخدم، وإنشاء تكليفات مستقلة لكل حساب ومهمة، ثم متابعة العمل وإرسال ردود محددة مسبقًا إلى الرسائل الأصلية بعد التأكيد. تُحفظ الحسابات والمهام وسجلات المصدر بصورة منفصلة حتى لا تضيع الأعمال السابقة أو تتكرر خطأً.

## البنية المستهدفة
- **New-VPS / Ubuntu:** خدمة TypeScript دائمة لاستقبال الرسائل، تطبيق القواعد، المعالجة، قاعدة البيانات، واجهة API، الإشعارات، وطابور الردود.
- **Windows / WinUI 3:** واجهة تحكم عربية RTL؛ لا تعتمد معالجة الرسائل على تشغيل اللابتوب. الاتصال بالخادم عبر قناة آمنة.
- **PostgreSQL:** مصدر البيانات المركزي؛ تشفير حقول الاعتماد والحالة الحساسة، مع نسخ احتياطي واختبار استعادة.
- **واتساب:** موصل معزول قابل للاستبدال؛ جلسة واحدة في النسخة الأولى، مع بنية تدعم تعدد الجلسات. طريقة الربط غير الرسمية تحتاج تقييمًا واعتمادًا للمخاطر قبل الاستخدام.
- **الذكاء الاصطناعي:** تكامل اختياري مع DeepSeek وOpenRouter، ولا تُرسل أسرار الحسابات إلى النماذج افتراضيًا.

## الحدود الأساسية
1. كل حساب كيان مستقل عن المهام؛ قد يتكرر وصوله دون تكرار سجله. كل تكليف يحتفظ بمجموعته وجلسة واتساب ورسالة المصدر.
2. الإكمال ليس حذفًا. لكل مهمة حالة وسجل مستقل، ولكل رد خارجي تأكيد وسجل إرسال ومنع تكرار.
3. اكتشاف رمز/كلمة مرور خاطئة يحتاج دليل تحقق فعلي أو تأكيدًا يدويًا؛ مجرد رسالة غير واضحة لا تثبت الخطأ.
4. الحذف الفردي والجماعي مقصودان، مع معاينة وتأكيد وإجراءات أمنية ضد الحذف غير المقصود.
5. لا إجراءات فعلية على الخوادم أو إرسال جماعي أو حذف فعلي قبل إقرار الخطوة واختبارها. وثائق الخطة ليست دليلًا على اكتمال التنفيذ.

المفاتيح تقرأ من ملفات خارج Git. راجع `.env.example` و`docs/12_API_CONTRACT.md` و`tracking/PROJECT_STATE.md` للحالة المثبتة. موصل mock افتراضي وموصل Baileys خلف بوابتين مستقلتين. الإعداد الافتراضي يعطل الاتصال والإرسال؛ في النسخة الشخصية وافق المالك على اتصال QR ثم فعّل الإرسال اليدوي وفق D-088. كل رد يحتاج اعتماده الخاص. اختبارات المعالجة تستخدم بيانات وهمية معزولة.

## Windows
البناء: dotnet restore apps/windows/TaskPilot.Windows.csproj --locked-mode ثم dotnet build apps/windows/TaskPilot.Windows.csproj -c Release -p:Platform=x64 --no-restore (.NET10). الحزمة الشخصية عربيةRTL وx64/self-contained ولا تحتاج SDK أو توقيعًا عند تشغيلها. افتح اختصار TaskPilot: يستعيد ملف ربط هذا الجهاز عبر Tailscale، دون مهلة جلسة. إعداد جهاز جديد من «ربط هذا الجهاز عبر Tailscale» يحتاج اتصال SSH محفوظًا وموثوقًا للتهيئة، ثم HTTPS الخاص. ملف العميل محمي بـWindows DPAPI لهذا المستخدم؛ لا تُنسخ مفاتيح المالك الدائمة أو بيانات الحسابات إلى الحزمة. العمليات الحساسة تحتفظ بتحقق قصير ولمرة واحدة. الاتصال اليدوي وSSH المؤقت بدائل متقدمة للتشخيص؛ الحالة الحالية والأدلة في التتبع.
