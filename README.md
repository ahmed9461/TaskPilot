# TaskPilot

**نظام لإدارة حسابات العمل والمهام المستلمة من مجموعات واتساب، مع تطبيق Windows وخدمة مركزية دائمة على New-VPS.**

> الحالة: **Backend وتطبيق Windows تجريبيان منفذان** — خدمة مغلقة على New-VPS واختبارات ببيانات وهمية؛ قبول الإنتاج ما زال مفتوحًا. آخر تحديث: 2026-11-11.

## الرؤية
استقبال الرسائل من مجموعات محددة مرتبطة بجلسات واتساب، واستخراج بيانات الحسابات بإشراف المستخدم، وإنشاء تكليفات مستقلة لكل حساب ومهمة، ثم متابعة العمل وإرسال ردود محددة مسبقًا إلى الرسائل الأصلية بعد التأكيد. تُحفظ الحسابات والمهام وسجلات المصدر بصورة منفصلة حتى لا تضيع الأعمال السابقة أو تتكرر خطأً.

## البنية المستهدفة
- **New-VPS / Ubuntu:** خدمة TypeScript دائمة لاستقبال الرسائل، تطبيق القواعد، المعالجة، قاعدة البيانات، واجهة API، الإشعارات، وطابور الردود.
- **Windows / WinUI 3:** واجهة تحكم عربية RTL؛ لا تعتمد معالجة الرسائل على تشغيل اللابتوب. الاتصال بالخادم عبر قناة آمنة.
- **PostgreSQL:** مصدر البيانات المركزي؛ تشفير حقول الاعتماد والحالة الحساسة، مع نسخ احتياطي واختبار استعادة.
- **واتساب:** موصل معزول قابل للاستبدال؛ جلسة واحدة في النسخة الأولى، مع بنية تدعم تعدد الجلسات. طريقة الربط غير الرسمية تحتاج تقييمًا واعتمادًا للمخاطر قبل الاستخدام.
- **الذكاء الاصطناعي:** تكامل اختياري مع DeepSeek وOpenRouter، ولا تُرسل أسرار الحسابات إلى النماذج افتراضيًا.

## الحدود الأساسية
1. كل حساب كيان مستقل عن المهام؛ قد يتكرر وصوله دون تكرار سجله. كل تكليف يحتفظ بمجموعته وجلسة واتساب ورسالة المصدر.
2. الإكمال ليس حذفًا. لكل مهمة حالة وسجل مستقل، ولكل رد خارجي تأكيد وسجل إرسال ومنع تكرار.
3. اكتشاف رمز/كلمة مرور خاطئة يحتاج دليل تحقق فعلي أو تأكيدًا يدويًا؛ مجرد رسالة غير واضحة لا تثبت الخطأ.
4. الحذف الفردي والجماعي مقصودان، مع معاينة وتأكيد وإجراءات أمنية ضد الحذف غير المقصود.
5. لا إجراءات فعلية على الخوادم أو إرسال جماعي أو حذف فعلي قبل إقرار الخطوة واختبارها. وثائق الخطة ليست دليلًا على اكتمال التنفيذ.

## سياسة المستودع
المستودع **عام حاليًا**. يُمنع تمامًا رفع قواعد بيانات، نسخ احتياطية، ملفات جلسات واتساب، أرقام خاصة، كلمات مرور، رموز ربط، محتويات محادثات، مفاتيح OpenRouter/DeepSeek، سجلات خام، أو ملفات .env حقيقية. استخدم بيانات اختبار وهمية فقط.

## التشغيل والتطوير
Node 24: `npm ci` ثم `npm run check`. PostgreSQL: `DATABASE_URL` ثم `npm run migrate`. اختبارات DB تتطلب `TASKPILOT_TEST_DATABASE_URL` بقاعدة مستقلة تنتهي `_test` ثم `npm run test:integration`.
المفاتيح تقرأ من ملفات خارج Git. راجع `.env.example` و`docs/12_API_CONTRACT.md` و`tracking/PROJECT_STATE.md` للحالة المثبتة. موصل وهمي فقط، لا ربط أو إرسال حقيقي.

## Windows
`dotnet restore apps/windows/TaskPilot.Windows.csproj --locked-mode` ثم `dotnet build apps/windows/TaskPilot.Windows.csproj -c Release -p:Platform=x64 --no-restore` (.NET10 SDK). التطبيق عربيRTL، x64 self-contained، لا يحتاج SDK عند تشغيل الحزمة المنشورة. افتح TaskPilot.Windows.exe ثم الإعدادات واختر «اتصال عبر SSH» مع اسم الاتصال المحفوظ والموثوق New-VPS. ينشئ التطبيق نفقًا محليًا وجلسة مؤقتة لمدة 30 دقيقة؛ إعادة التحقق للعمليات الحساسة عبر SSH صالحة 60 ثانية ولمرة واحدة. لا تنقل مفاتيح API الدائمة إلى التطبيق، ولا توجد مفاتيح داخل الحزمة. يتطلب ذلك إعداد SSH موثوقًا مسبقًا؛ ليس تسجيل دخول إنتاجيًا أو MFA. بعد انتهاء الجلسة اتصل مجددًا. أدخل رسالة وهمية من صندوق المراجعة بعد إنشاء جلسة ومهمة ومجموعة لمحاكاة العمل.
