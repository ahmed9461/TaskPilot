# قاموس الأخطاء والتنبيهات

| Code | المعنى | ما يعرض للمستخدم | الإجراء |
|---|---|---|---|
| ACCOUNT_PASSWORD_INVALID_VERIFIED | كلمة مرور حساب غير صحيحة بدليل | «تم التحقق أن كلمة مرور الحساب غير صحيحة» | مراجعة ورد قالب بعد موافقة |
| ACCOUNT_CODE_INVALID_VERIFIED | رمز وصول حساب غير صحيح بدليل | «رمز الحساب غير صحيح» | مراجعة ورد قالب بعد موافقة |
| ACCOUNT_CREDENTIALS_UNVERIFIED | لا يوجد دليل كافٍ | «تعذر التحقق من بيانات الحساب» | طلب مراجعة؛ لا اتهام بالخطأ |
| WHATSAPP_PAIRING_CODE_INVALID | رمز اقتران جلسة منتهي/غير صالح | «رمز ربط واتساب غير صالح أو منتهي» | إعادة الاقتران |
| WHATSAPP_DISCONNECTED | انقطع اتصال الجلسة | «رقم واتساب غير متصل» | تنبيه/إعادة اتصال بضوابط |
| MESSAGE_MISSING_FIELDS | رسالة ناقصة | «بيانات الحساب ناقصة» | صندوق الوارد للمراجعة |
| DUPLICATE_SOURCE_MESSAGE | حدث استلام مكرر | لا إشعار متكرر | تجاهل آمن |
| DUPLICATE_ASSIGNMENT | المهمة نفسها موجودة | «المهمة مسجلة سابقًا» | ربط المصدر وإظهار الموجود |
| REPLY_DELIVERY_UNKNOWN | إرسال دون نتيجة حاسمة | «يحتاج تحقق من وصول الرد» | لا إعادة إرسال تلقائي |
| REPLY_SEND_FAILED | رفض أو فشل مؤكد | «تعذر إرسال الرد» | تكرار محكوم بعد تصحيح |
| ACCOUNT_DELETE_REQUIRES_REAUTH | حذف حساس بدون إعادة تحقق | «أكد هويتك لإتمام الحذف» | إيقاف الحذف |
| DATABASE_UNAVAILABLE | تعذر الوصول للبيانات | «الخدمة متعذرة مؤقتًا» | إعادة المحاولة دون فقدان الطلب |
| AI_UNAVAILABLE | مزود AI غير متاح | «التحليل الذكي متوقف مؤقتًا» | القواعد والمراجعة |

لا تُعرض قيم كلمات المرور أو رموز الوصول في التنبيهات أو السجلات أو رسائل الأخطاء، ولا يُستنتج الخطأ الصحيح من تخمين نموذج لغوي فقط.
