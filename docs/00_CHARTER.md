# ميثاق المشروع — TaskPilot

**النسخة:** 0.1 تخطيطية | **التاريخ:** 2026-11-11 | **الحالة:** Approved scope, no implementation.

## الهدف
إدارة حسابات وتكليفات العمل المستلمة عبر مجموعات واتساب المصرح بها، وربط التكليفات بالمجموعات والرسائل والجلسات، وإظهارها في تطبيق Windows، وإرسال ردود موافق عليها من المستخدم عند إنهاء العمل أو ظهور خطأ.

## المخرجات المستهدفة
- خدمة مركزية مستمرة على New-VPS لا تعتمد على وجود اللابتوب.
- واجهة Windows عربية RTL، وإشعارات وأقسام للحسابات والمهام والردود والمجموعات والجلسات والإعدادات.
- جلسة واتساب واحدة تشغيلية عند إطلاق النسخة الأولى، ببنية تدعم عدة جلسات مستقلة.
- حساب فريد منطقيًا يمكن ربطه بعدة أنواع من المهام عبر مجموعات ورسائل مختلفة.
- حذف/أرشفة/استرجاع مع سجل عمليات وضمان منع الحذف الخاطئ.
- تحليل قواعد أولًا، وذكاء اصطناعي اختياري عند الحاجة مع مراجعة بشرية للنتائج غير الواضحة.

## غير مطلوب في النسخة الأولى
- تنفيذ المهام نفسها أو تسجيل دخول آلي إلى حسابات جهات خارجية.
- ترويج جماعي أو نشر رسائل عشوائية أو مراقبة مجموعات غير محددة.
- تطبيق Android أو لوحة تحكم عامة مكشوفة للإنترنت.
- إرسال كلمات المرور إلى نماذج AI.

## معايير جودة أولية
- استعادة الخدمة بعد إعادة تشغيل VPS وعودة المعالجة دون ازدواج الرسائل/المهام.
- منع الرد المتكرر لنفس الطلب وإيضاح حالة التسليم/الفشل/المجهول.
- سرعة فتح الواجهة وعرض البيانات المحفوظة، وقابلية الفلترة والبحث.
- نسخ احتياطي مشفر مجرب الاستعادة؛ سجل تدقيق منفصل ومحدود البيانات.
- اختبارات نجاح/فشل قبل وصف أي ميزة بأنها جاهزة.

## قاعدة الموافقات
العمل في المستودع مسموح لتنظيم المشروع؛ أما الربط الفعلي بواتساب، نشر الخدمة، فتح منافذ عامة، وإرسال أو حذف بيانات حقيقية فتحتاج موافقة منفصلة.
