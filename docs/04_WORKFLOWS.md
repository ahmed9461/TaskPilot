# سير العمل وحالات الانتقال

## استلام الرسائل
1. تتحقق الخدمة من session_id وحالة المجموعة وربط المهمة/قواعدها.
2. تحفظ معرف الرسالة في inbox بمفتاح تفرد؛ الرسائل المكررة لا تنشئ مهام.
3. تطبق تنقية الرسائل واستخراج الحقول بالقواعد، ثم AI اختياري لنص غير منظم وبعد تقليل البيانات.
4. عند نقص اليوزر أو تضارب المعطيات: مراجعة بشرية + تنبيه؛ لا تُخترع بيانات.
5. عند مطابقة حساب قائم: يستخدم account_id نفسه أو يعرض احتمال التعارض. تنشأ Assignment جديدة عند اختلاف المهمة/الفترة، وتُربط الرسالة بالمهمة القائمة عند تطابق المفتاح.
6. تعرض Windows قائمة المستلم الجديد والحالة والمجموعة/الجلسة/الوقت دون كشف كلمة المرور في التنبيه.

## دورة حياة المهمة
NEW → IN_PROGRESS → COMPLETED؛ ويمكن تحويلها إلى NEEDS_REVIEW أو CANCELED حسب الصلاحية، وإعادة فتح مهمة مكتملة بإجراء مسجل. اكتمال المهمة لا يعني حذف الحساب أو إرسال رد.
المهمة قد تكون COMPLETED بينما الرد PENDING_APPROVAL أو SENDING أو SENT أو FAILED أو UNKNOWN_DELIVERY.

## الردود السريعة
- المستخدم يختار تكليفًا وقالبًا محفوظًا، ويعاين رقم الجلسة واسم المجموعة والرسالة المقتبسة والنص النهائي.
- تعتمد واجهة الطلب على server-side approval token قصير المدة، ثم تسجل في outbox.
- يرسل Worker ردًا مقتبسًا على external_message_id بواسطة نفس session_id. إذا حُذفت الرسالة أو لم يعد المرسل/المجموعة متاحًا، تعاد حالة صريحة للمراجعة.
- لا تفسر انقضاء مهلة الشبكة بعد send على أنه فشل مؤكد: UNKNOWN_DELIVERY يطلب تحققًا ولا يعاد إرساله آليًا بلا ضمان منع تكرار.
- القوالب: «تم حل الذاتي ✅»، «تم الانتهاء من الدوري الثاني ✅»، «الرمز المرسل غير صحيح، يرجى مراجعته» بعد تحقق أو إقرار.
- الإرسال التلقائي غير مفعل افتراضيًا؛ لا إرسال جماعي غير مطلوب.

## رمز غير صحيح
- INVALID_ACCOUNT_PASSWORD أو INVALID_ACCOUNT_CODE: يضاف flag مع دليل ووسيلة تحقق أو تأكيد بشري؛ المهمة تنتقل إلى NEEDS_REVIEW أو BLOCKED حسب القرار، ويرسل تنبيهًا.
- INVALID_PAIRING_CODE: يظهر في صفحة الجلسات فقط مع إعادة توليد الرمز إذا أمكن؛ لا يُنشأ Account أو Assignment.
- UNVERIFIED: مشكلة محتملة لا تُعامل كحقيقة؛ لا يتم إرسال رد يؤكد خطأ بيانات الحساب.
- قد يحتاج الرد للمرسل الأصلي فقط أو للمجموعة؛ يتم اختيار القناة عمدًا، ولا توضع الأسرار في الرد.

## الحذف
اختيار الحسابات → معاينة الاسم والعدد والمهام المرتبطة والردود المعلقة → قرار Archive أو Permanent Delete → تأكيد إضافي للحذف النهائي، وعبارة تأكيد مكتوبة للحذف الكلي → تنفيذ في معاملة محكومة → سجل تدقيق منقح ونتائج جزئية قابلة للفهم. لا يحذف ذلك رسائل واتساب من أجهزة الآخرين.
