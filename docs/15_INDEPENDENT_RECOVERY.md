# الاستعادة المستقلة — Windows / 0.8

هذه الطريقة تستعيد نسخة مشفرة وتختبر سلامتها دون الخادم أو DPAPI أو ملف Windows الشخصي الأصلي. تحتاج الحزمة المشفرة ورمز الاستعادة المنفصل؛ لا تعني نشر خادم بديل تلقائيًا. D-065 هو قرار الحدود والتشفير.

## الإنشاء والتشغيل
النسخ الخاصة في E:\TaskPilot-Backups خارج Git وoutputs، بصلاحيات المالك وSYSTEM. التهيئة مرة واحدة: `node scripts/offhost-backup.mjs --init-independent`. تحفظ مفتاح RSA4096 مشفرًا بـscrypt N32768/r8/p1 وAES256GCM، والرمز العشوائي256bit في ملف منفصل داخل D:\TaskPilot-Recovery-Key. لا تطبع الرمز أو تنقله إلى المحادثة أو المستودع. احتفظ بنسخة منه خارج اللابتوب لحمايته من فقد الجهاز بالكامل.

`--upgrade-owner-escrows` يضيف غلاف مالك مشفرًا إلى النسخ القديمة دون تغييرها، مع التحقق من فكها ومطابقة SHA256. النسخ الجديدة تضيف الغلاف تلقائيًا؛ المهمة اليومية تحتاج المفتاح العام فقط ولا تقرأ رمز الاستعادة. تبقى أغلفة DPAPI وVPS الأصلية ونسخها القديمة محفوظة.

لبناء حزمة قابلة للنقل: `node scripts/build-independent-kit.mjs offhost-TIMESTAMP.tpg` مع اسم النسخة الفعلي؛ يمكن إدخال حتى10 أسماء. يقبل أسماء ثابتة دون مسارات، ويتحقق من التشفير/الحجم/البصمة/المستلم وصلاحيات المجلد. الحزمة تضم فقط النسخ المشفرة وmanifest وowner envelopes والمفتاح الخاص المشفر والمفتاح العام وأربع أدوات استعادة وتعليمات. يقرأ كل إدخال مجددًا من ZIP ويطابق SHA256؛ لا يقرأ الرمز أو DPAPI أو custodian أو original escrow. رفع الحزمة إلى مخزن خاص إجراء مستقل، وليس تلقائيًا بالمهمة اليومية.

فك الحزمة في مجلد جديد مثل E:\TaskPilot-Recovery-OwnerDrill، وشغّل PowerShell داخله:

```powershell
$env:TASKPILOT_RECOVERY_ROOT='E:\TaskPilot-Recovery-OwnerDrill'
node .\offhost-backup.mjs --recover-independent offhost-TIMESTAMP.tpg 'X:\private-folder\recovery-code.txt'
```

استبدل الاسم والمسار بمعلوماتك؛ لا تضع قيمة الرمز في الأمر. يتطلب Windows وNode24 وDocker Desktop وصورة PostgreSQL17 المثبتة بالبصمة في الأداة؛ جلب الصورة لأول مرة يحتاج الإنترنت. حاوية الاستعادة نفسها network=none ودون منافذ، بموارد محدودة وتخزين مؤقت، وتزال بعد الفحص. لا يبدأ API أو واتساب ولا يرسل رسائل. يحظر هذا الوضع SSH وDPAPI في الأداة.

## معنى الدليل وحدوده
تتحقق الأداة من جميع حقول الاعتماد وauth والمراجعة والاقتباس والوارد وفق AAD الخاص بها، ووجود المهاجرات، وعدم إدخال مكرر، ولنسخ13+ من سياسة الاحتفاظ وسجل النسيان وعدم بقاء auth لجلسة منسية. التقرير أعداد فقط؛ لا يكتب dump أو مفاتيح رئيسية صريحة على القرص. الرمز الخاطئ أو الغلاف المعدل يرفض قبل بدء الحاوية. لا يعدل قاعدة الإنتاج. تشغيل خادم بديل يحتاج هدفًا مستقلًا ومراجعة منع ازدواج هوية واتساب وخطة رجوع؛ لا تبدأ النسخة القديمة المتصلة تلقائيًا.
