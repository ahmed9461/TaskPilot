# مشكلات محتملة ومعالجة أولية

| السيناريو | الاستجابة المطلوبة | التأكد |
|---|---|---|
| انقطاع واتساب أو انتهاء الجلسة | حالة واضحة وتنبيه وإعادة اتصال محدودة؛ لا حذف تلقائي | اختبار قطع/استعادة |
| تعطيل رقم واتساب | توقف الإرسال المعني وإشعار؛ فحص سياسة المزود | محاكاة حالة موصل |
| تغيير واجهة Baileys | قفل إصدار واختبارات توافق وترقية متدرجة | تكامل |
| رمز اقتران منتهي/غير صحيح | إظهار خطأ الجلسة دون خلطه بخطأ حساب | UI + unit |
| كلمة مرور خاطئة لحساب | لا تأكيد بلا دليل؛ مراجعة ورد اختياري | integration |
| رسالة ناقصة/غير مفهومة | صندوق مراجعة دون تخمين | parsing |
| بيانات لحسابين متشابهين | لا دمج بالاسم فقط | dedupe |
| نفس الحساب بعدة مهام | حساب واحد وتكليفات منفصلة | integration |
| مهمة دورية في فصل جديد | period_key جديد يحفظ التاريخ | data |
| رسالة تصل مرتين | مفتاح idempotency يمنع التكرار | concurrency |
| نتيجة إرسال مجهولة | UNKNOWN_DELIVERY وتحقيق قبل الإعادة | outbox |
| تعطل AI/انتهاء الرصيد | استمرار قواعد محلية؛ تنبيه غير معطل | provider fault |
| توقف Windows | الخدمة تستمر والخادم يحتفظ بالإشعارات | E2E |
| توقف New-VPS أو DB | تنبيه، إعادة تشغيل، نسخ احتياطية واستعادة | disaster recovery |
| تضارب تحديثين من نافذتين | optimistic locking ومراجعة تعارض | concurrency |
| حذف كلي بالخطأ | إعادة تحقق ومعاينة وعدد وتأكيد كتابي | security test |
| تسريب أسرار في log | تنقيح تلقائي، تدوير أسرار، مسار استجابة | security |
| المجموعة محذوفة/غير متاحة | إيقاف الإرسال ووضع الجلسة/الرد للمراجعة | provider |
| مصادر مكررة عبر جلستين | تفرد رسالة بحسب session/group؛ دمج حساب مشروط | integration |
| فشل استعادة نسخة احتياطية | لا يعد backup ناجحًا حتى اختبار restore | restore drill |
