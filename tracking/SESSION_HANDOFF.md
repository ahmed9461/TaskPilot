# تسليم جلسة العمل التالية

**التاريخ:** 2026-11-11  
**الجلسة:** تأسيس المشروع  
**الحالة:** وثائق قيد الإضافة إلى مستودع TaskPilot.

## تم
- الاتفاق على البنية المستهدفة Windows + New-VPS الدائم.
- تنظيم المتطلبات والحسابات والمهام والردود والتكاملات وحالات الخطأ والحذف.
- إعداد ملفات ذاكرة مستدامة وتتبع مخاطر وخطة واختبارات وقرار.
- لا كود تنفيذي ولا نشر فعلي.

## الخطوة التالية
- قراءة AGENTS.md والوثائق وقائمة TODO؛ تثبيت القرارات المفتوحة.
- بدء تطوير الهيكل البرمجي والمخططات باستخدام عينات وهمية واختبارات أولية.
- عدم توصيل رقم واتساب فعلي قبل مراجعة موصل الرسائل وقبول مخاطره.

## نقاط تحتاج حسمًا أثناء التطوير
1. موصل واتساب: دعم المجموعات الموجودة، مسار توافقه ومخاطر المخالفة.
2. معنى «رمز غلط» في بيانات العمل إن كانت رموز تحقق أو كلمة مرور أو كلاهما؛ صممت البنية لدعم كل الحالات مع دليل.
3. سياسة حذف نهائي واحتفاظ وأثر النسخ الاحتياطية.
4. خيارات ربط عميل Windows بـ New-VPS وطرق المصادقة.
5. عدد مستخدمي التطبيق (مبدئيًا مالك واحد، قابل للتوسع).

## التزام الجلسة المقبلة
لا تعاود طرح أسئلة حُسمت هنا، ولا تعتبر خطط النشر خطوات منفذة، وحدّث هذا الملف بعد كل تسليم.
